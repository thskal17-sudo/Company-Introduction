# 회사 소개서 작성 양식

아래 내용을 채워서 보내주시면 그대로 소개서에 반영합니다.
모르거나 없는 항목은 비워 두거나 "없음"이라고 적어 주세요. 비운 항목은 소개서에서 자동으로 빠집니다.

## 2. 강사 소개 — 분야별 대표 강사

이름과 분야는 반영했습니다. 나머지 칸을 채워 주시면 카드에 추가됩니다.
빈칸으로 두면 소개서에서 그 항목만 빠집니다.

| 분야 | 이름 | 직함 | 전문 분야 (최대 3개) | 한 줄 소개 문구 | 주요 경력 | 자격 | 사진 파일 |
|---|---|---|---|---|---|---|---|
| 대표 · 자소서 | 박서현 | 대표 강사 |  |  |  |  | `daepyo.jpg` |
| 이미지 | 허나영 | 이미지 분야 대표 강사 |  |  |  |  | `image.jpg` |
| 스피치 | 이석희 | 스피치 분야 대표 강사 |  |  |  |  | `speech.jpg` |
| AI | 강명주 | AI 분야 대표 강사 |  |  |  |  | `ai.jpg` |

- 소개서에는 4명이 **한 페이지에 한 줄로** 들어갑니다.
- 전문 분야나 한 줄 소개를 넣으면 카드가 채워져 페이지가 더 알차 보입니다.
- 경력·학력·자격을 **전부 다 보여주고 싶으면** 말씀해 주세요. 한 명씩 자세히 소개하는 배치로 바꿀 수 있습니다.

## 3. 이미 넣은 내용 중 확인 부탁드리는 것

기존 소개서 이미지에서 읽어 옮긴 내용이라 글자가 다를 수 있습니다.
**맞으면 "맞음", 다르면 올바른 문장**을 적어 주세요.

| 항목 | 현재 들어간 내용 | 확인 |
|---|---|---|
| 대표자 이름 | 박서현 | ✅ 확인 완료 |
| 인사말 전체 문장 | data/company.yaml 의 `greeting` 참고 |  |
| 영문명 | Korea Expert Education Institute |  |
| 슬로건/태그라인 | 학생에 맞춘 혁신적인 경력과 창업 교육을 지원합니다 |  |
| 핵심 가치 "디지털 기초 소양" 설명 | AI 시대에 필요한 디지털 도구 활용 능력을 기초부터 탄탄하게 다집니다 |  |
| AI 투어 메이커 부제 | 기초부터 실전 취업까지, 관광고등학교 맞춤형 3단계 성장 로드맵 |  |
| 2학년 M2 "프리미엄 여행 포토" 설명 | AI 사진 편집·마케팅 이미지 제작 → 시그니처 홍보물 |  |
| 3학년 모듈 | M1. AI 자기소개서·면접 코칭 (M2 가 더 있는지?) |  |

## 4. 사진  (선택 — 지금은 사진 없이 진행 중)

사진 없이도 완성된 형태로 만들어 두었습니다. 나중에 사진을 주시면 넣어 드립니다.

| 용도 | 파일명 | 장수 | 권장 |
|---|---|---|---|
| AI 투어 메이커 수업 | `ai-tour-1.jpg` ~ `ai-tour-3.jpg` | 3장 | 가로 사진 |
| 취업·진로 교육 현장 | `career-1.jpg` ~ `career-3.jpg` | 3장 | 가로 사진 |
| 직업체험 현장 | `job-1.jpg` ~ `job-3.jpg` | 3장 | 가로 사진 |
| 강사 프로필 | `daepyo.jpg`, `image.jpg`, `speech.jpg`, `ai.jpg` | 4장 | 세로 사진, 3:4 비율 |

- 파일명을 맞추기 어려우면 그냥 보내주셔도 됩니다. 제가 이름을 바꿔서 넣겠습니다.
- 얼굴이 나오는 사진은 본인(학생은 학교·보호자) 동의를 받은 것만 보내주세요.

## 5. 있으면 좋은 내용  (없으면 건너뛰셔도 됩니다)

| 항목 | 예시 |
|---|---|
| 주요 숫자 | 누적 교육 학교 수, 누적 수강생 수, 교육 만족도 |
| 연혁 | 연도별 주요 사건 (설립, 프로그램 출시, 기관 선정 등) |
| 교육한 학교·기관 목록 | 소개서에 "주요 고객사"로 들어갑니다 |
| 후기 | 담당 선생님이나 학생 후기 한두 개 |
| 차별화 포인트 | "무엇이 다른가" 외에 추가로 강조할 강점 |
