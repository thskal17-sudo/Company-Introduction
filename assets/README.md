# 이미지 파일 안내

이 폴더에 아래 이름으로 파일을 넣으면 소개서에 자동으로 들어갑니다.

**지금 소개서는 사진 없이 만들어져 있습니다.** 사진 없이도 완성된 모습이 되도록
프로그램 페이지는 내용 카드로, 강사 페이지는 이름 이니셜 원형으로 표시됩니다.

사진을 넣으려면 파일을 이 폴더에 넣고 `data/company.yaml` 에서 해당 `photos` / `photo` 항목의
주석을 해제한 뒤 다시 생성하면 됩니다.

## 로고

| 파일 | 쓰이는 곳 |
|---|---|
| `logo.png` | 흰 배경 페이지 (마지막 페이지, Word 표지) |
| `logo-white.png` | 어두운 표지와 뒷표지 |
| `logo-vertical.png` | 예비용 (현재 소개서에는 사용하지 않음) |

## 프로그램 사진 — `assets/programs/`

| 파일 | 들어가는 페이지 |
|---|---|
| `ai-tour-1.jpg` ~ `ai-tour-3.jpg` | AI 투어 메이커 프로그램 |
| `career-1.jpg` ~ `career-3.jpg` | 취업·진로 교육 프로그램 |
| `job-1.jpg` ~ `job-3.jpg` | 직업체험 |
| `startup-1.jpg` ~ `startup-3.jpg` | 창업 교육 프로그램 |

- 가로 사진을 권장합니다. 짧은 변이 800px 이상이면 인쇄해도 깨지지 않습니다.
- 장수를 늘리거나 줄이려면 `data/company.yaml` 의 해당 프로그램 `photos` 목록을 고치면 됩니다.
- 사진이 3의 배수면 3열, 그 외에는 2열로 배치됩니다.

## 활동 사진 — `assets/activity/`

소개서에 **활동 사진** 페이지가 있습니다. 아래 이름으로 넣으면 한 페이지에 모아 보여줍니다.

| 파일 | 내용 |
|---|---|
| `activity-1.jpg` | 고등학교 취업역량강화 교육 |
| `activity-2.jpg` | 수업을 마친 학생들 |
| `activity-3.jpg` | 진로·취업 워크시트 작성 |
| `activity-4.jpg` | 팀 활동 중심 직업체험 |
| `activity-5.jpg` | 조별 발표와 피드백 |

**얼굴은 모두 모자이크 처리된 상태로 저장되어 있습니다.** 원본이 아니라 처리본만 저장소에 있습니다.

- 가로 사진을 권장합니다. 6장 이하면 2열, 7장 이상이면 3열로 배치되고, 홀수면 마지막 한 장이 가로로 꽉 찹니다.
- 장수를 바꾸려면 `data/company.yaml` 의 `gallery.photos` 목록을 고치면 됩니다.
  7장 이상이면 `gallery.per_page` 만큼 나눠 여러 페이지가 만들어집니다.
- 사진마다 `caption` 에 짧은 설명을 적으면 사진 아래에 표시됩니다.

## 강사 사진 — `assets/instructors/`

**현재 소개서에서 강사 소개 페이지는 빠져 있습니다.** 다시 넣을 때 쓰는 파일명입니다.

| 파일 | 분야 | 강사 |
|---|---|---|
| `daepyo.jpg` | 대표 · 자소서 · 창업 | 박서현 |
| `image.jpg` | 이미지 | 허나영 |
| `speech.jpg` | 스피치 | 이석희 |
| `ai.jpg` | AI | 강명주 |

- 세로 사진을 권장합니다. 가로 세로 비율 3:4 정도가 가장 잘 맞습니다.
- 사진이 없으면 이름 첫 글자로 된 동그란 아바타가 대신 들어갑니다.

## 주의

얼굴이 나오는 사진은 본인 동의를 받은 것만 사용해 주세요. 학생 사진은 특히 학교나 보호자 동의가 필요할 수 있습니다.
