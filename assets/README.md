# 이미지 파일 안내

이 폴더에 아래 이름으로 파일을 넣으면 소개서에 자동으로 들어갑니다.
파일이 없는 동안에는 소개서에 점선으로 된 **사진 자리**가 표시됩니다.

## 로고

| 파일 | 쓰이는 곳 |
|---|---|
| `logo.png` | 흰 배경 페이지 (마지막 페이지, Word 표지) |
| `logo-white.png` | 어두운 표지와 뒷표지 |
| `logo-vertical.png` | 예비용 (현재 소개서에는 사용하지 않음) |

## 프로그램 사진 — `assets/programs/`

| 파일 | 들어가는 페이지 |
|---|---|
| `ai-tour-1.jpg` ~ `ai-tour-3.jpg` | AI 투어 메이커 프로그램 |
| `career-1.jpg` ~ `career-3.jpg` | 취업·진로 교육 프로그램 |
| `job-1.jpg` ~ `job-3.jpg` | 직업체험 |

- 가로 사진을 권장합니다. 짧은 변이 800px 이상이면 인쇄해도 깨지지 않습니다.
- 장수를 늘리거나 줄이려면 `data/company.yaml` 의 해당 프로그램 `photos` 목록을 고치면 됩니다.
- 사진이 3의 배수면 3열, 그 외에는 2열로 배치됩니다.

## 강사 사진 — `assets/instructors/`

분야별 대표 강사 5명의 사진 자리가 아래 이름으로 잡혀 있습니다.

| 파일 | 분야 |
|---|---|
| `daepyo.jpg` | 대표 |
| `image.jpg` | 이미지 |
| `speech.jpg` | 스피치 |
| `resume.jpg` | 자소서 |
| `ai.jpg` | AI |

- 세로 사진을 권장합니다. 가로 세로 비율 3:4 정도가 가장 잘 맞습니다.
- 사진이 없으면 이름 첫 글자로 된 동그란 아바타가 대신 들어갑니다.

## 주의

얼굴이 나오는 사진은 본인 동의를 받은 것만 사용해 주세요. 학생 사진은 특히 학교나 보호자 동의가 필요할 수 있습니다.
